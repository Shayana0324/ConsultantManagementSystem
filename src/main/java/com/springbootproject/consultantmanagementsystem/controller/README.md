# Consultant Management System

A Java Spring Boot web application for managing consultant information.

## Tech Stack

- Java 17
- Spring Boot 3.3.4 (Spring MVC, Spring Data JPA, Spring Validation)
- Thymeleaf (server-side HTML templates)
- MySQL 
- Maven (build tool)

## Features

- Add / edit / delete consultants with server-side validation
- Search by name or technology
- Sortable, paginated results table (bonus features)
- Dashboard with total / active / inactive consultant counts
